# Userstories

## Userstories door Gerjan

| Title | bekijken van planningen|
| ----------- | ----------- |
| Als een  | deelnemer |
| Wil ik | planning kunnen bekijken |
| Zodat | ik weet wanneer ik ergens moet zijn |
| Prioriteit | Must Have |
| Tijd | 2 dagen |
| Acceptatiecriteria | - Elke deelnemer kan op elk moment kijken naar de planning<br> - De planning ziet er duidelijk uit<br> - Een deelnemer kan zonder permissions niet de planning aanpassen en echt alleen bekijken|
| Scenario | Scenario:<br> Gegeven dat een deelnemer weet dat er een evenement aan komt<br> Wanneer ze willen weten wat de datum en tijd is<br> Dan kunnen ze de planning bekijken op de website<br>  En zien wanneer dat evenement in de planning staat|

| Title | stemmen van polls|
| ----------- | ----------- |
| Als een  | deelnemer |
| Wil ik | kunnen stemmen op polls |
| Zodat | ik duidelijk aan kan geven wanneer ik beschikbaar ben |
| Prioriteit | Must Have |
| Tijd | 2 dagen |
| Acceptatiecriteria | - deelnemers kunnen stemmen op polls<br> - Er kunnen meerdere vakjes worden aangeklikt in de polls<br> - deelnemers kunnen stemmen weer verwijderen|
| Scenario | Scenario:<br> Gegeven dat de planner moet weten op welke datums mensen beschikbaar zijn<br> Wanneer hij/zij een planning wil maken<br> Dan kunnen mensen stemmen op die poll <br>  En weet de planner op deze manier welke dagen hij het beste kan inplannen|

| Title | Deelnemers aanroepen om poll in te vullen |
| ----------- | ----------- |
| Als een  | planner |
| Wil ik | deelnemers kunnen herinneren aan het invullen van polls |
| Zodat | ik de planning zo snel mogelijk kan maken. |
| Prioriteit | Must Have |
| Tijd | 2 dagen |
| Acceptatiecriteria | - deelnemers die al wel de pol hebben ingevult moeten niet herinnerd worden<br> - de deelnemers die nog niet de poll in hebben gevult wanneer de planner op de knop drukt krijgen een mail met een reminder<br> - de planner kan instellen dat de deelnemers na een bepaalde tijd automatisch een reminder krijgen via de mail |
| Scenario | Scenario:<br> Gegeven dat de planner over een week de planning klaar wil hebben<br> Wanneer 2 mensen nog niet de poll hebben ingevult<br> Dan kan de planner op de knop drukken<br> En worden de 2 mensen herinnerd dat ze de poll nog moeten invullen |
