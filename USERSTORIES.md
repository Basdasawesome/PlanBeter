| Title | bekijken van planningen|
| ----------- | ----------- |
| Als een  | deelnemer |
| Wil ik | planning kunnen bekijken |
| Zodat | ik weet wanneer ik ergens moet zijn |
| Prioriteit | Must Have |
| Tijd | 2 dagen |
| Acceptatiecriteria | - Elke deelnemer kan op elk moment kijken naar de planning<br> - De planning ziet er duidelijk uit<br> - Een deelnemer kan zonder permissions niet de planning aanpassen en echt alleen bekijken|
| Scenario | Scenario:<br> Gegeven dat een deelnemer weet dat er een evenement aan komt<br> Wanneer ze willen weten wat de datum en tijd is<br> Dan kunnen ze de planning bekijken op de website<br>  En zien wanneer dat evenement in de planning staat|

| Title | Deelnemers aanroepen om poll in te vullen |
| ----------- | ----------- |
| Als een  | planner |
| Wil ik | deelnemers kunnen herinneren aan het invullen van polls |
| Zodat | ik de planning zo snel mogelijk kan maken. |
| Prioriteit | Must Have |
| Tijd | 2 dagen |
| Acceptatiecriteria | - deelnemers die al wel de pol hebben ingevult moeten niet herinnerd worden<br> - de deelnemers die nog niet de poll in hebben gevult wanneer de planner op de knop drukt krijgen een mail met een reminder<br> - de planner kan instellen dat de deelnemers na een bepaalde tijd automatisch een reminder krijgen via de mail |
| Scenario | Scenario:<br> Gegeven dat de planner over een week de planning klaar wil hebben<br> Wanneer 2 mensen nog niet de poll hebben ingevult<br> Dan kan de planner op de knop drukken<br> En worden de 2 mensen herinnerd dat ze de poll nog moeten invullen |

## Userstories Ezra

### Story - Enkel evenement plannen (te breed)

| **Titel**              | Enkel evenement plannen |
|------------------------|------------------------|
| **Als een**            | Gebruiker |
| **Wil ik**             | een datum vinden voor een eenmalig evenement |
| **Zodat**              | de meeste uitgenodigden aanwezig kunnen zijn |
| **Prioriteit**         | Must have |
| **Tijd**               | 1 week |
| **Acceptatiecriteria** | - De planner moet een aantal data opgeven als opties<br>- Uitgenodigden moeten hun beschikbaarheid kunnen invullen<br> - De resultaten moeten worden weergegeven met een percentage van de totale beschikbaarheid <br> - Een datum moet bevestigd kunnen worden |
| **Scenario**           | **Scenario:**<br> Gegeven dat ik een evenement wil plannen<br> Wanneer ik meerdere data opties invoer en deel met de doelgroep<br> Dan kunnen de uitgenodigden hun beschikbaarheid opgeven<br> En ziet iedereen de beschikbaarheid als percentage van het totaal |

### Story - Beschikbaarheid opgeven

| **Titel**              | Beschikbaarheid opgeven |
|------------------------|------------------------|
| **Als een**            | Gebruiker |
| **Wil ik**             | De data waarop ik beschikbaar ben makkelijk kunnen opgeven |
| **Zodat**              | Ik meegenomen kan worden in de planning |
| **Prioriteit**         | Must have |
| **Tijd**               | 2 dagen |
| **Acceptatiecriteria** | - Er is een optie om aan te geven op welke data je beschikbaar bent<br> - Voor elke data kan je minimaal aangeven ja, twijfel, of nee voor beschikbaarheid<br> - Je kan de data nadertijd nog aanpassen |
| **Scenario**           | **Scenario:**<br> Gegeven dat er een evenement wordt georganiseert<br> Wanneer ik mijn beschikbaarheid opgeef per datum<br> Dan wordt mijn beschikbaarheid opgeslagen<br> En wordt ik meegenomen in de berekening van de beste datum |
